---
title: Setting up Node.js Environment
---

wapi.js 0.2 requires **Node.js 20 or later**. It uses the built-in `fetch`, `FormData`, `Blob` and Web Crypto APIs, which is why it has no runtime dependencies.

<Tip>
Check your version:
```bash
node -v
```
Any `v20.x` or later works. If you have Node 18 or older, upgrade before installing wapi.js 0.2.
</Tip>

<Note>
  To mount the webhook with `client.webhook.fetchHandler`, you can also run on Bun, Deno, Cloudflare Workers or another edge runtime. The built-in server (`client.webhook.listen()`) needs Node.js.
</Note>

## Installing Node.js

<Tabs>
  <Tab title="Windows">
    <Steps>
      <Step title="Download Node.js">
        Download the LTS installer from [nodejs.org](https://nodejs.org/en/download/).
      </Step>
      <Step title="Install">
        Run the installer and follow the instructions.
      </Step>
      <Step title="Check the installation">
        Open a new terminal and run `node -v`.
      </Step>
    </Steps>
  </Tab>
  <Tab title="macOS">
    Use a version manager such as `n`:
    <Steps>
      <Step title="Install n">
        ```bash
        curl -L https://bit.ly/n-install | bash
        ```
      </Step>
      <Step title="Reload your shell">
        Close and reopen the terminal, or run `source ~/.zshrc` (or the profile of the shell you use).
      </Step>
      <Step title="Install the LTS release">
        ```bash
        n lts
        ```
      </Step>
      <Step title="Check the installation">
        ```bash
        node -v
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="Linux">
    Use a version manager such as `nvm`:
    <Steps>
      <Step title="Install nvm">
        ```bash
        curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
        ```
      </Step>
      <Step title="Reload your shell">
        Close and reopen the terminal, or run `source ~/.bashrc`.
      </Step>
      <Step title="Install the LTS release">
        ```bash
        nvm install --lts
        nvm use --lts
        ```
      </Step>
      <Step title="Check the installation">
        ```bash
        node -v
        ```
      </Step>
    </Steps>
  </Tab>
</Tabs>
