title: Quick Start Guide
description: "Get a WhatsApp bot answering messages in a few minutes."
---

You need Node.js 20 or later, plus a Meta app with WhatsApp set up. If you don't have the app yet, follow [WhatsApp API setup](/guide/whatsapp-api-setup/understanding-whatsapp-business-platform) first. You will need:

- an access token
- the phone number id (and the WhatsApp Business Account id if you manage templates, numbers or catalogs)
- a verify token: any string you choose and also enter in the Meta dashboard
- your app secret, found under *App settings → Basic*

## 1. Create a project

To scaffold a bot:

```bash
npm create wapi-app my-whatsapp-bot
```

Or add the SDK to an existing project:

## 2. Write the bot

```ts
// src/index.ts
import { Client, TextMessage } from "@wapijs/wapi.js";

const client = new Client({
  accessToken: process.env.WHATSAPP_API_ACCESS_TOKEN!,
  phoneNumberId: process.env.WHATSAPP_PHONE_NUMBER_ID,
  businessAccountId: process.env.WHATSAPP_BUSINESS_ACCOUNT_ID,
  webhook: {
    verifyToken: process.env.WHATSAPP_WEBHOOK_VERIFY_TOKEN!, // what you type in the Meta dashboard
    appSecret: process.env.META_APP_SECRET, // App settings → Basic → App secret
  },
});

client.on("TextMessage", async (event) => {
  await event.markAsRead({ typingIndicator: true });
  await event.reply(new TextMessage({ text: `You said: ${event.text}` }));
});

client.on("Error", (error) => console.error(error));

const { port, path } = await client.webhook.listen({ port: 8080, path: "/webhook" });
console.log(`Webhook ready on :${port}${path}`);
```

## 3. Connect the webhook

1. Expose port 8080 to the internet. For local development a tunnel is enough: `cloudflared tunnel --url http://localhost:8080`.
2. In the Meta app dashboard, set the callback URL to `https://<your-domain>/webhook` and the verify token to the same `WHATSAPP_WEBHOOK_VERIFY_TOKEN`.
3. Subscribe to the `messages` webhook field.

[Configuring the webhook](/guide/whatsapp-api-setup/configuring-webhook) walks through each step.

Message your business number from WhatsApp. The bot should answer.
