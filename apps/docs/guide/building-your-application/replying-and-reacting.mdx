---
title: Replying and Reacting to messages
description: Learn how to reply and react to messages using the Wapi.js SDK
---

Every [message event](/guide/building-your-application/event-handling#message-events) has four helpers. They always act **from the business number that received the message**, and they address the sender by phone number, or by BSUID when the sender has no visible number.

| Helper | |
|---|---|
| `event.reply(message)` | Sends `message` to the sender, quoting this message |
| `event.send(message)` | Sends `message` to the sender without quoting |
| `event.react(emoji)` | Reacts to this message; `""` removes the reaction |
| `event.markAsRead({ typingIndicator? })` | Blue ticks, optionally with a typing indicator |

`reply`, `send` and `react` resolve with the same response as [`send()`](/guide/building-your-application/sending-messages) (including `messageId`), and throw a `GraphApiError` when Meta rejects the request.

## Replying

```ts
import { TextMessage, ButtonInteractionMessage } from "@wapijs/wapi.js";

client.on("TextMessage", async (event) => {
  await event.markAsRead({ typingIndicator: true });

  if (event.text.toLowerCase() === "hi") {
    await event.reply(new TextMessage({ text: `Hello ${event.senderName ?? "there"}!` }));
    return;
  }

  await event.send(
    new ButtonInteractionMessage({
      bodyText: "How can we help?",
      buttons: [
        { id: "order", title: "My order" },
        { id: "agent", title: "Talk to us" },
      ],
    }),
  );
});
```

Any component works with `reply()` and `send()`: media, lists, templates and so on.

## Reacting

```ts
client.on("ImageMessage", async (event) => {
  await event.react("👀");
  // ...process the image...
  await event.react("✅"); // replaces the previous reaction
});
```

To react outside a listener, send a `ReactionMessage`:

```ts
import { ReactionMessage } from "@wapijs/wapi.js";

await client.message.send({
  to: "15550001111",
  message: new ReactionMessage({ messageId: "wamid.HBgL...", emoji: "👍" }),
});
```

## Replying later

To answer after the listener has returned (for example, from a job queue), keep the ids you need and send through the right number:

```ts
client.on("TextMessage", async (event) => {
  await queue.add({
    phoneNumberId: event.phoneNumber.id,
    to: event.from || { userId: event.fromUserId! },
    messageId: event.messageId,
  });
});

// in the worker
await client.messaging(job.phoneNumberId).message.send({
  to: job.to,
  replyToMessageId: job.messageId,
  message: new TextMessage({ text: "Your report is ready" }),
});
```

<Note>Outside the 24-hour customer service window, WhatsApp only accepts [template messages](/guide/building-your-application/building-message-components#templates). A free-form reply then fails with a `GraphApiError` (code `131047`).</Note>

## Who sent it, and what it replies to

```ts
client.on("TextMessage", (event) => {
  event.from; // sender's phone number / wa_id
  event.fromUserId; // sender's BSUID, when Meta includes it
  event.context.repliedToMessageId; // the message the user quoted, if any
  event.context.forwarded;
  event.messaging.phoneNumberId; // the business number that received it
});
```
