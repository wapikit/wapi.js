title: Creating the client
---

One `Client` covers a whole WhatsApp Business Account: every phone number in it, its templates, catalogs and webhooks.

<Tip>Need the token, ids and app secret? Follow the [WhatsApp API setup guide](/guide/whatsapp-api-setup/understanding-whatsapp-business-platform) first.</Tip>

```ts
import { Client } from "@wapijs/wapi.js";

export const client = new Client({
  accessToken: process.env.WHATSAPP_API_ACCESS_TOKEN!,
  businessAccountId: process.env.WHATSAPP_BUSINESS_ACCOUNT_ID, // templates, phone numbers, catalogs
  phoneNumberId: process.env.WHATSAPP_PHONE_NUMBER_ID, // default number for client.message
  webhook: {
    verifyToken: process.env.WHATSAPP_WEBHOOK_VERIFY_TOKEN!, // the token you enter in the Meta dashboard
    appSecret: process.env.META_APP_SECRET, // verifies X-Hub-Signature-256 (recommended)
  },
});
```

## Sending from several numbers

```ts
const support = client.messaging("<support phone number id>");
const sales = client.messaging("<sales phone number id>");

await sales.message.send({ to: "15550001111", message });
```

Events always reply from the number the message was received on (`event.messaging`).

## Receiving webhooks

Register listeners, then start the built-in server:

```ts
client.on("TextMessage", async (event) => {
  await event.reply(new TextMessage({ text: "Hello!" }));
});

await client.webhook.listen({ port: 8080, path: "/webhook" });
```

Or mount the handler in your own server: see [Using your own server](/guide/building-your-application/using-your-own-server).

## Options

| Option | Default | |
|---|---|---|
| `accessToken` | required | System user token |
| `phoneNumberId` | — | Default number for `client.message` / `client.media` |
| `businessAccountId` | — | Needed for templates, phone numbers, catalogs, business |
| `apiVersion` | `"v20.0"` | Graph API version |
| `graphBaseUrl` | `"https://graph.facebook.com"` | Override for tests |
| `fetch` | `globalThis.fetch` | Custom fetch |
| `timeoutMs` | `60000` | Per request timeout |
| `logger` | warn/error to console | Any `{ debug, info, warn, error }` logger |
| `webhook.verifyToken` | — | Required to receive webhooks |
| `webhook.appSecret` | — | Enables signature verification |
| `webhook.port` / `host` / `path` | `8080` / all interfaces / `/webhook` | Built-in server |
