## What is wapi.js?

wapi.js is the TypeScript SDK for the WhatsApp Cloud API. Use it to build chat bots, or to add WhatsApp messaging to a backend you already run. It is at parity with [wapi.go](https://github.com/wapikit/wapi.go), its Go sibling.

```ts
import { Client, TextMessage } from "@wapijs/wapi.js";

const client = new Client({
  accessToken: process.env.WHATSAPP_API_ACCESS_TOKEN!,
  phoneNumberId: process.env.WHATSAPP_PHONE_NUMBER_ID,
  webhook: {
    verifyToken: process.env.WHATSAPP_WEBHOOK_VERIFY_TOKEN!,
    appSecret: process.env.META_APP_SECRET,
  },
});

client.on("TextMessage", async (event) => {
  await event.reply(new TextMessage({ text: `You said: ${event.text}` }));
});

await client.webhook.listen({ port: 8080 });
```

Also included:

- **Multiple numbers.** `client.messaging(phoneNumberId)` sends from any number of your WhatsApp Business Account. Events reply from the number that received the message.
- **Identity ready.** Events carry business-scoped user ids (BSUID) and usernames, and you can send to `{ userId }`.
- **Zero runtime dependencies.** ESM and CommonJS builds with full type definitions. Requires Node.js 20+; `fetchHandler` also runs on Bun, Deno and edge runtimes.
