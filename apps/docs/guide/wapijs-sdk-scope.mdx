## Current status (0.2 beta)

<Card>
  wapi.js covers the WhatsApp Cloud API end to end: every outgoing message type (including templates, interactive, location request and commerce messages), every inbound message, status and business-account webhook, media, and the Business Management API (templates, phone numbers, catalogs, analytics, webhook app subscriptions). It is at parity with [wapi.go](https://github.com/wapikit/wapi.go).
</Card>

## Upcoming features

- [Interactive address messages](https://developers.facebook.com/docs/whatsapp/cloud-api/messages/address-messages)
- WhatsApp Payments API
- WhatsApp Flows management (creating and publishing flows; receiving flow replies is already supported)
- Calling API
