# Variable: MessageLimits

> `const` **MessageLimits**: `object`

Defined in: packages/wapi.js/src/components/validation.ts:8

Limits enforced by the WhatsApp Cloud API on outgoing messages. Components
validate against these in their constructors so mistakes surface as a
[ValidationError](../classes/ValidationError.mdx) before a request is made.
