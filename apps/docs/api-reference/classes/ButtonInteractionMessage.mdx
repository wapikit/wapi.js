# Class: ButtonInteractionMessage

Defined in: packages/wapi.js/src/components/button.ts:47

An interactive message with up to three quick reply buttons.

## Example

```ts
new ButtonInteractionMessage({
  header: "Order #42",
  bodyText: "Did your order arrive?",
  footerText: "Reply within 24h",
  buttons: [
    { id: "yes", title: "Yes" },
    { id: "no", title: "No" },
  ],
});
```
