Defined in: [packages/wapi.js/src/components/commerce.ts:126](https://github.com/wapikit/wapi.js/blob/beta/packages/wapi.js/src/components/commerce.ts#L126)

Multi product message (MPM): shows up to 30 catalog products in sections.

## Example

```ts
new ProductListMessage({
  catalogId: "123",
  header: "Summer sale",
  bodyText: "Pick your favourites",
  sections: [{ title: "Shoes", productRetailerIds: ["sku-1", "sku-2"] }],
});
```
