# Abstract Class: BaseMessage\<T\>

Defined in: [packages/wapi.js/src/components/base.ts:53](https://github.com/wapikit/wapi.js/blob/beta/packages/wapi.js/src/components/base.ts#L53)

Base class for every outgoing message component. Subclasses implement
[BaseMessage.content](#content) (the type specific object); the envelope
(`to`/`recipient`, `context`, ...) is shared.
